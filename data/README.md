# Task data

All task data in Upgrade Gate is **synthetic and license-free**: every name, phone number,
email (only `example.*` domains), GSTIN, invoice and price was generated by code in this repo.
No external dataset is downloaded or redistributed. Answers are computed in code, never typed by
hand.

Load packs with:

```python
from upgrade_gate.packs import load_pack
tasks = load_pack("math-pairs")              # all tasks, fixed content
tasks = load_pack("math-pairs", n=60, seed=1)  # seeded sample, pair groups kept together
```

Task content and ids are fixed (fixed internal seed); `seed` only picks which tasks a sampled
`n` returns. Paired items (for H6, English vs Hindi/Hinglish) carry `pair_id` = id of the English
twin, and `meta["group"]` = the English id for every member. Scorer spec types are documented at
the top of [`upgrade_gate/packs/__init__.py`](../upgrade_gate/packs/__init__.py).

| Pack | Category | en | hi | hinglish | Modality | Scorer |
|---|---|---:|---:|---:|---|---|
| `math-pairs` | math | 120 | 120 | 120 | text | `number`, `one_of` |
| `extract-pairs` | extraction | 80 | 80 | 80 | text | `json_fields` |
| `intent` | classification | 255 | – | 120 | text | `label` |
| `ifeval` | instruction | 100 | 50 | – | text | `ifeval` |
| `docs-synth` | doc-image | 60 docs | 40 docs | – | image + pdf (2 tasks per doc = 200) | `json_fields` |
| `canary` | mixed | 40 | 7 | 3 | text | canary check types |

## Packs

**math-pairs** — word problems in six families, 20 each: shopping totals in ₹ (total, change
from a note, % discount), percentages (of, increase, decrease, marks), time arithmetic (arrival
time in HH:MM, minutes between times), unit conversion, day-of-week offsets, simple interest.
Each item is generated once and phrased in English, Hindi (Devanagari) and romanised Hinglish
with the same numbers. Digits stay ASCII. Every prompt ends with "reply with only the number"
(or the day name / HH:MM) in its language. Weekday answers accept English, Devanagari and
romanised spellings.

**extract-pairs** — short messages (orders, contacts, appointments, invoices; 20 each per
language) with JSON field extraction: names, order/invoice ids, quantities, ₹ amounts (Indian
digit grouping, some with paise), 10-digit phone numbers written as `+91 98765 43210` /
`98765-43210` / `098765 43210`, ISO dates from "14 March 2026" / "14 मार्च 2026" / `14/03/2026`, 24-hour
times from "4:30 PM" / "शाम 4:30 बजे". Names, cities and vendors are accepted in Latin or
Devanagari.

**intent** — banking customer-support intent classification over 15 labels
(`account_statement, activate_card, balance_inquiry, card_declined, card_lost,
cash_withdrawal_failed, change_address, close_account, exchange_rate, order_cheque_book,
refund_request, reset_pin, transfer_failed, unrecognized_transaction, update_phone_number`).
Written from templates with fillers (amounts, merchants, card last-4, cities), prefixes and
suffixes. 17 English + 8 Hinglish per intent; every Hinglish item is a translation of an English
item with the same fillers. A public set such as **Banking77** (CC-BY-4.0) could replace or
extend this later; it was not used here so the repo needs no network and carries no third-party data.

**ifeval** — IFEval-style verifiable instructions: a writing task on one of 25 everyday topics
plus 1–2 checkable rules (word-count range, no commas, all caps, all lowercase, starts/ends with,
exact line count, bullet count, must / must-not include a word, JSON with given keys). 50 Hindi
items mirror 50 English items (same topic and rule parameters) and add a Devanagari-ratio rule.

**docs-synth** — synthetic Indian GST invoices and cash receipts rendered by headless Chrome
from HTML templates (`scripts/build_assets.py`), as PNG (900×1200) and single-page A4 PDF.
Ground truth = the values used to render: vendor, invoice number, date (shown in several
formats), line items, subtotal, GST (as one line or split CGST + SGST), total. 4 layouts
(classic table, thermal receipt, modern banded, bordered grid with CGST/SGST), 6 Latin fonts and
4 Devanagari fonts. Hindi docs 1–40 use the same numbers as English docs 1–40 (paired); half of
them are bilingual (Hindi labels such as "कुल", "दिनांक", "बिल संख्या" with English in brackets).
Every 5th document's PNG is a `rotated_noisy` variant (1–3.5° rotation, paper tint, stains,
speckle), done in CSS; its PDF stays clean. Files: `data/docs-synth/*.png|*.pdf` and
`manifest.jsonl` (one row per document). Rebuild with
`PYTHONPATH=. python3 scripts/build_assets.py` (macOS Chrome path by default; set `CHROME=`).

**canary** — `canary/prompts.json` (50 prompts) wrapped as Tasks; the canary `check` dict is
the scorer spec unchanged.
