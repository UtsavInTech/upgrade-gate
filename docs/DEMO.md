# Demo script
1. 0:00 — Open the dashboard, select `e1-upgrade`, and enter Presenter mode. “A model upgrade is a release decision, not just a better average.”
2. 0:15 — On the problem slide, describe the hypothetical support team whose English tickets look fine while a Hindi workflow changes; say this is the risk, not an E1 finding.
3. 0:30 — Press → for the real verdict. “We ran 1,325 tasks on both versions, three repeats each. This content gate says GO on this suite.”
4. 0:45 — Point at the before/after panel. “The first scorer said +1.13 points, p about 0.000061. We inspected the answers and the improvement disappeared.”
5. 1:05 — Press → for the slice map. “Corrected content change is zero across the observed slices. Grey means no clear change, not proof of universal safety.”
6. 1:25 — Press → for the saved answer. Read its Hindi spelling or wrapped answer beside the reference and rule. “Same response, corrected scoring. Content and format stay separate.”
7. 1:50 — Show an individual repeat and its content/strict labels. “Repeats measure inconsistency; we count the task once. We did not pay for another call to rescore it.”
8. 2:10 — Press → for cost. “The run cost is recorded; per-1,000-task figures normalize to one response each. Contributor repricing is labeled an estimate, not an E3 result.”
9. 2:30 — Press → for the three commands. “Exit 0 can continue a deploy; 2 blocks it; 3 asks for more evidence. Reports and regression tests make the decision reviewable.”
10. 2:50 — Close with: “Utsav designed and ran the study. Claude Code and Codex helped write the code. Our useful surprise was finding the evaluator's mistake before trusting the upgrade claim.”
